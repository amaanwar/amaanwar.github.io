PROJECT / MEDICAL IMAGE ANALYSIS

Automated Brain MRI Segmentation

Developing an image-processing pipeline for preclinical MRI.

Overview

This project focused on segmenting mouse brain MRI and assessing the quality of computational segmentation.

Methods

Used MATLAB for image processing, atlas comparisons, coil intensity correction, and evaluation using Dice similarity and SSIM.

Outcomes

The pipeline supported repeatable segmentation comparisons. Add representative images and validated metrics when available.
