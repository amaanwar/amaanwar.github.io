# Ama Anwar — GitHub Pages Portfolio

A personal portfolio inspired by the friendly, project-forward layout of the reference site. This is an original design, not a copy.

## Publish
1. Upload **the contents** of this folder (not the outer folder) to your GitHub Pages repository.
2. Go to Settings → Pages → Deploy from branch → main / root.
3. Wait for deployment and open your GitHub Pages URL.

## Edit
- `index.html`: homepage, About, experience, and contact information.
- `styles.css`: fonts, colors, layout, and illustrative project visuals.
- `script.js`: one-time typing animation.
- `projects/*.html`: individual project detail pages.
- `assets/Ama_Anwar_CV.pdf`: add your own CV PDF, then set `data-ready="true"` on the CV link in `index.html`.

**Important:** Replace sample contact links and placeholder project visuals with your own materials. Project descriptions are concise summaries for review, not verified final project statements.
