# Ama Anwar — Personal Portfolio

A static personal academic portfolio ready for GitHub Pages.

## Publish
1. Create a public GitHub repository named `YOUR_USERNAME.github.io` (replace YOUR_USERNAME with your GitHub username).
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root (not the enclosing `ama-portfolio` folder).
3. In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
4. Visit `https://YOUR_USERNAME.github.io/` after deployment.

## Customize before sharing
- In `index.html`, replace `YOUR_EMAIL@example.com` and generic LinkedIn/GitHub URLs.
- Review the biographical and experience descriptions for accuracy and preferred wording.
- To add a CV, place `Ama_Anwar_CV.pdf` in `assets/`, then add `data-ready="true"` to the CV link in `index.html`.
- Edit sections in `index.html`, colors and typography in `styles.css`.
- No build tools required. Google Fonts requires internet access; system fallbacks are included.
